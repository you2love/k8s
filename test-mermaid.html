测试Mermaid图表渲染

这个页面用于测试Mermaid图表是否能正确渲染。打开浏览器的开发者工具（F12）查看控制台输出。

测试1：简单流程图

flowchart TD
    A[开始] --> B[处理数据]
    B --> C{检查结果}
    C -->|成功| D[显示成功]
    C -->|失败| E[显示错误]
    D --> F[结束]
    E --> F

测试2：时序图

sequenceDiagram
    participant 用户
    participant 服务器
    participant 数据库
    
    用户->>服务器: 发送请求
    服务器->>数据库: 查询数据
    数据库-->>服务器: 返回结果
    服务器-->>用户: 返回响应

测试3：状态图

stateDiagram-v2
    [*] --> 空闲
    空闲 --> 处理中: 开始处理
    处理中 --> 完成: 处理成功
    处理中 --> 错误: 处理失败
    完成 --> [*]
    错误 --> [*]
